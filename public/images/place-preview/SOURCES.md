# Place photo sources

These copies are stored locally so showing a place list does not make image API requests. Wikimedia copies were served as 960 px thumbnails; the source file links and licenses follow. No other changes were made.

The app reads the place-to-file mapping and display attribution from Oracle `COMM_PLACE_PHOTO`. `server/sql/02_place_photo_metadata.sql` seeds the initial rows. This file documents the rights and original sources for the repository assets.
