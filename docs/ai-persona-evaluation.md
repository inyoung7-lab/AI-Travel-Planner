# AI 가상 페르소나 모의 평가

평가일: 2026-10-26 (한국 시간)

## 평가 성격

실제 사람 5명이 참여한 사용자 테스트가 아니다. 하나의 AI가 5가지 가상 사용자 관점에서 공개 서비스의 API 응답과 기존 구현을 검토했다. 외부 사용자 참여 인원은 0명이며 과제의 ‘실사용자 최소 5명 피드백’ 충족 근거로 사용하지 않는다. 아래 개선 의견은 AI의 제안이며 실제 사용자의 발언·설문 응답이 아니다.

대상: https://ai-travel-planner-pi-indol.vercel.app

신규 계정·일정·게시글을 만들거나 실제 사용자 데이터를 수정하지 않았다. API 확인만으로 전체 화면의 사용성, 모바일 동작, 로그인 후 저장과 재조회 성공을 판단하지 않았다.

## 관점별 확인 결과와 개선 제안

| 구분 | 가상 사용자 관점 | 수행한 확인 | 실제 결과 | AI의 개선 제안 |
| --- | --- | --- | --- | --- |
| P01 | 처음 방문한 여행자 | 검색 이력 없이 추천 API 요청 | 200, 인기 여행지 8곳 반환. 개인 맞춤으로 표시하지 않음 | 인기 목록이 강원 지역에 치우쳐 있어, 지역 다양성을 선택할 수 있는 기능을 검토한다. 상단 인기 순위와 겹치는 장소가 많으므로 추천 영역의 역할도 구분하면 좋다. |
| P02 | 제주 여행을 준비하는 여행자 | 여행지 목록에서 제주 지역 필터 API 요청 | 500, ‘여행지 목록을 불러오지 못했어요.’ | 지역 필터 오류를 먼저 재현·수정해야 한다. 실패를 ‘여행지 없음’으로 표현하지 않고 재시도 안내와 검색 조건을 보존한다. |
| P03 | 일정 작성이 익숙하지 않은 여행자 | 과거 날짜로 AI 일정 생성 요청 | 400, 지난 날짜 제한을 설명하는 한글 메시지 반환 | 날짜 입력 단계에서 제한 이유를 보여주고, 오류가 나도 다른 입력값을 유지한다. 이 검사는 잘못된 날짜 차단만 확인하며 정상 AI 생성 품질 평가는 별도다. |
| P04 | 개인정보 보호를 중요하게 생각하는 여행자 | 비로그인 상태에서 나의 여행 API 요청 | 401, ‘로그인이 필요해요.’ 반환. 저장 버튼의 비로그인 차단은 기존 코드 검토 | 로그인 필요 안내를 사용자가 누른 버튼 가까이에 표시한다. 로그인 이동 후 생성한 초안이 사라지지 않도록 초안 보존 흐름을 후속 검토한다. 실제 로그인 후 저장·재접속은 이번 검사에 포함하지 않았다. |
| P05 | 후기를 읽고 작성하려는 여행자 | 커뮤니티 게시글 목록 API 요청 | 200, 게시글 20개 반환 | 개발 샘플과 실제 후기의 구분을 유지한다. 신규 사진 업로드가 준비 중인 현재 상태를 명확히 안내하고, 후기 작성·등록·재조회는 실제 사용자 과제로 확인한다. |

## 우선순위

1. 높음: 제주 지역 필터의 500 오류를 재현하고 수정한다.
2. 중간: 첫 방문 추천의 지역 편중과 상단 인기 순위 중복을 개선한다.
3. 중간: 로그인 이동 전후의 일정 초안 보존을 검증한다.
4. 후속: 실제 사람 5명 이상에게 탐색·찜·AI 생성·직접 수정·저장·리뷰 과제를 제공하고 의견을 받는다.

## 실제 사용자 테스트로 보완할 사항

이번 기록에는 만족도, 완료 시간, 추천 정확도 점수, 사용자 인용문을 만들지 않았다. 실제 참가자의 동의를 받아 익명 ID·수행 날짜·성공 여부·막힌 단계·자유 의견을 기록하고, 수정 후 재검증한다. API 기대 응답 4건과 실패 1건은 사람 5명의 과제 성공률로 환산하지 않는다.
