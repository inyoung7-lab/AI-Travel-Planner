## 변경 내용

세 체험을 `PUBLISHED`, 세 회차를 `RECRUITING`으로 변경했다. 체험의 시연 플래그를 해제하고 `demo_code`를 비웠으며, HOST가 확인하지 않은 실제 진행 언어는 빈 배열로 통일했다. 한국어·영어·일본어 소개와 포함 사항에서 시연·신청 불가 문구를 제거하고 일반 체험 설명으로 바꿨다. 회차 날짜, 정원, 표시 회비는 유지했다. 영어·일본어 번역 검수 상태는 계속 `DRAFT`다.

## 사후 검증

Supabase publishable key로 공개 조회를 수행해 세 체험, 세 회차, 세 장소 주소가 익명 공개 API에서 조회되는 것을 확인했다. 관리 권한 조회에서 세 체험은 모두 PUBLISHED, 세 회차는 모두 RECRUITING이며 전체 신청 1건·결제 안내 1건, 체험 15건·회차 19건으로 기존 수량이 유지됐다. 새 신청이나 결제 행은 생성하지 않았다.

세 회차의 실제 참가 신청은 일반 신청 화면에서 접수 RPC로 처리된다. 결제 행은 기존 구현대로 `DEMO_ONLY` 안내이며 실제 결제·입금 처리는 제공하지 않는다. HOST 언어 확인 전까지 언어별 진행 가능 필터에는 포함되지 않는다.
