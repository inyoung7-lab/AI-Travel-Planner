# 발표 흐름과 핵심 메시지

## 발표의 중심

로컬이음은 관광지를 소개하는 데서 멈추지 않고, 여행자가 그곳에서 지역 주민을 만나 함께 일상을 경험하도록 연결하는 서비스입니다. 지역 주민은 자신의 이야기와 관심사를 바탕으로 체험을 만드는 호스트가 됩니다.

> 여행에서 만남으로, 만남에서 새로운 경험으로.

## 12장 구성

1. 로컬이음의 기획 방향과 실제 화면
2. 여행자와 호스트가 겪는 문제, 서비스의 역할
3. 체험 탐색부터 신청과 호스트 운영까지의 흐름
4. 현재 앱에서 확인한 체험 목록·상세·공개 호스트 데모
5. Supabase에 저장된 체험과 회차 데이터 현황
6. React 화면, Supabase 데이터, AI 기획 지원 구조
7. 호스트의 아이디어를 돕는 AI Agent
8. 화면 번역과 실제 진행 가능 언어의 구분
9. 구현 및 테스트 근거와 현재 개발 상태
10. 실제 운영을 위해 남은 검증 항목
11. “관광지에서 사람으로, 정보에서 경험으로”라는 기획 의도
12. 기획 의도를 이어가는 개발 방향

## 발표에서 전달할 점

화면과 데이터 기능은 직접 구현했으며, 시연 가능한 부분과 아직 운영 검증이 필요한 부분을 구분해 설명합니다. AI는 호스트의 기획을 돕는 제안 도구이고 결과는 호스트가 확인합니다. 실제 결제, 검수 완료 번역, 실사용자 평가가 끝난 것처럼 표현하지 않습니다.
