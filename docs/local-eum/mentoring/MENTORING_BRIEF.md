# 로컬이음 1페이지 요약

**관광지에서 사람으로, 정보에서 경험으로**
로컬이음은 국내외 여행자와 지역 주민을 연결해 시장·골목·음식·언어와 문화를 함께 경험하도록 돕는 로컬 체험 서비스입니다. 여행자는 지역의 일상에 참여하고, 주민은 자신의 이야기와 관심사로 경험을 만드는 호스트가 됩니다.

## 구현 결과

React·Vite 화면에 Supabase PostgreSQL 기반 체험 탐색, 상세·회차 확인, 참가 신청과 HOST 운영센터를 연결했습니다. 한국어·영어·일본어 화면, 주소 기반 Kakao 지도 검색, AI 기획 Agent를 구성했습니다. AI는 지역 자료와 기존 체험을 바탕으로 아이디어·가치·비용·운영 유의점을 제안하고, HOST가 검토하고 편집해 활용합니다.

2026년 10월 20일 개발 DB 조회 기준으로 HOST 2명, 체험 15개, 운영 회차 19개가 등록되어 있습니다. 이 수치는 개발 DB의 조회 시점 현황입니다.

## 개발에서 배운 점

서비스를 구현하는 일은 화면을 늘리는 것만으로 끝나지 않았습니다. 여행자와 호스트의 업무 흐름을 먼저 정하고, 그 흐름에 필요한 데이터 저장·권한·신청·다국어·AI 기능을 연결해야 했습니다. 기능의 수보다 처음 정의한 문제를 실제 사용 흐름으로 풀어내는 설계가 중요하다는 점을 배웠습니다.

## 기능 범위

참가 신청 접수와 회비 표시는 구현되어 있지만 실제 결제·환불·정산 기능은 포함하지 않습니다. AI 결과는 자동 확정·저장되지 않으며 HOST가 검토한 뒤 활용합니다.
