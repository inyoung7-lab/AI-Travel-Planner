# 호스트 운영센터

진입 경로는 `/local-eum/host/profile`이다. HOST로 로그인하면 본인 호스트의 프로그램과 회차를 왼쪽에서 선택하고, 오른쪽에서 관리한다.

## 공개 데모

공유 경로는 `/local-eum/host/profile?demo=1`이다. 로그인 없이 `HostOperationsDemo`를 렌더링하며 실제 HOST 인증·운영 데이터 로더를 마운트하지 않는다. `hostOperationsDemo.js`의 두 가상 호스트, 프로그램, 회차, `example.com` 이메일과 가상 전화번호만 사용한다. 데모 호스트를 바꾸면 화면을 다시 마운트하여 이전 호스트의 선택 상태를 남기지 않는다.

실제 HOST 로그인 필요 여부와 읽기 전용·가상 데이터 표시를 상단에 유지한다. 프로그램 저장·회차 추가/취소는 비활성화한다. AI 화면은 저장된 UI 예시만 보여주고 모델 호출과 초안 저장을 하지 않는다. 데모 신청자 화면에서는 실제 연락 링크와 복사를 제공하지 않는다. Supabase RLS나 테이블 권한을 변경하지 않는다.

팀원·심사위원에게 전달할 외부 링크는 `https://팀의-배포주소/local-eum/host/profile?demo=1` 형태다. localhost/127.0.0.1 링크는 실행 중인 PC에서만 열리며, Git 병합만으로 외부 배포가 완료되지는 않는다. 사용 중인 팀 호스팅에 이 코드가 반영되어야 한다.

## 메뉴

- 운영현황: 내 프로그램 수, 운영 회차 수, 접수 중 신청 수와 다가오는 모집 회차.
- 프로그램·회차 관리: 체험 소개 / 일정·회비 / 상세 일정 / 여행자 미리보기. 기존 `SessionEdit`을 운영센터 내부에서 재사용한다. 회차 추가와 운영 취소는 일정·회비 탭에 있다.
- 신청자·연락처: 선택한 회차의 신청자를 20건씩 조회한다. 신청자를 선택하면 이름, 인원, 전화번호, 이메일, 연락 언어, 문의, 접수번호와 접수 유효기한을 표시한다. 만료된 접수도 남겨 두며 참가 확정으로 표시하지 않는다.
- AI 기획·진단: 선택한 체험·회차를 분석한다. HOST가 AI 운영안을 검토한 뒤 소개 초안으로 복사하면 프로그램 관리의 체험 소개 탭으로 전환한다. 실제 저장은 별도 저장 버튼으로 수행한다.
- 호스트 프로필: 모든 프로그램에서 공유하는 호스트 이름·소개와 번역 초안을 편집한다.

메뉴를 바꿔도 프로그램 편집과 AI 결과는 유지한다. 다른 프로그램·회차를 선택하면 현재 편집 내용의 폐기 여부를 확인한다. 프로필 초안은 부모 화면에서 유지한다. 로그아웃 시 미저장 프로그램/프로필 변경을 확인한다. 페이지를 떠난 뒤의 초안 영속 저장은 제공하지 않는다.

## 신청자 연락처

기존 `lc_applications` 컬럼을 조회하며 새로운 SQL은 필요하지 않다. 연락처는 신청자 메뉴를 열었을 때 선택한 회차 범위로 조회한다. `lc_my_host_id()`로 로그인한 본인의 호스트 ID를 대조하고, 본인 체험에 연결된 회차인지 검사한 다음 RLS가 적용된 사용자 클라이언트로 조회한다. 계정·호스트·회차를 바꾸거나 신청자 메뉴를 떠나면 이전 상세 조회 상태를 재사용하지 않는다. 연락처를 로컬 스토리지, URL, 로그에 기록하지 않는다.

전화번호/이메일 복사와 `tel:`/`mailto:` 링크를 제공한다. 전화 또는 이메일 발송은 사용자의 기기 앱에서 직접 수행한다. URL은 전화번호·이메일 형식을 확인하고 이메일 주소를 인코딩한다. 연락 완료 상태, HOST 메모, 승인·거절·환불·자동 알림은 이번 범위에 포함하지 않는다.

## 기존 DB 의존성

- 프로필 조회와 신청 테이블/RPC는 기존 적용본을 사용한다.
- 회차 추가/운영 취소 권한과 `lc_cancel_experience` RPC는 2026-10-20 `local-eum-dev`에 적용됐다. [적용 기록](migrations/20261020_language_friends_and_host_lifecycle.applied.md)에서 정책·제약·기존 데이터 보존 검증을 확인한다. HOST/ADMIN 계정별 실제 조작 테스트는 별도로 수행한다.
- 개발 DB에는 영어·일본어 `translations` 컬럼과 초안 콘텐츠가 적용되어 있다. 호스트별 소개, 소유 체험, 일정 번역을 검수해 사용할 수 있다. 다른 Supabase 환경에 적용됐다고 가정하지 말고, 배포 환경의 컬럼 적용 여부를 먼저 확인한다. 적용 건수와 `DRAFT` 검수 상태는 `local-eum-language-rollout.md`를 참고한다.
- AI Edge Function과 API 키는 기존 Supabase 프로젝트 설정을 사용한다. 신청자 연락처를 AI 컴포넌트에 전달하지 않는다.

## 검증

`npm run build`, `npm run lint`, `node --test src/pages/local-eum/*.test.js`를 실행한다. 순수 모델 테스트는 프로그램과 회차가 어긋난 선택의 보정, 범위 밖 신청 제외, 접수 만료, 연락처 URL의 파라미터 삽입 차단을 확인한다. 실제 브라우저에서 연락처 조회, 신청이 없는 회차로 전환, 메뉴를 왕복한 뒤 편집 초안 유지, 네 편집 탭, AI 실제 분석을 확인한다. 이 조회 검증은 다른 HOST 계정으로 로그인한 실제 교차 권한 테스트를 대신하지 않는다.
