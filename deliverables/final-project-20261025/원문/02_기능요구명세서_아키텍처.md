# 여행 한걸음 기능 요구 명세서

기능 요구사항과 비기능 요구사항, 시스템 구조 및 검증 기준

## 적용 범위

현재 구현한 여행자 서비스와 호스트 운영 기능을 대상으로 한다. 각 요구사항은 정상 흐름뿐 아니라 입력 오류, 권한 및 저장 실패 시의 동작을 함께 정의한다.

## 우선순위

P0는 서비스 핵심 흐름 또는 데이터 보호, P1은 주요 사용 편의 기능, P2는 확장 기능이다. 구현 여부는 코드 기준이며 실제 화면 전체 검수나 외부 배포 완료를 의미하지 않는다.

| 영역 | 사용자와 책임 |
| --- | --- |
| 여행자 | 탐색, 일정 생성 및 편집, 저장, 찜, 리뷰 |
| 호스트 | 본인 프로필과 승인된 범위의 체험·회차 운영 |
| 서버 | JWT 검증, 입력·결과 검사, 외부 서비스 연동 |
| 데이터 계층 | 회원별 소유권, 무결성 및 공개 범위 유지 |

참고: 시스템 기준 2026-10-25. 근거 파일과 테스트는 각 기능 영역 및 검증 문서에 연결했다.

# 비기능 요구사항



| ID | 요구사항 | 검증 기준과 현재 한계 |
| --- | --- | --- |
| NFR-01 | 보안과 개인정보 | JWT 및 RLS로 소유권을 검사한다. 서버 전용 키와 연락처를 공개 로그·번들에 노출하지 않는다. 가입 동의 이력은 보완 대상이다. |
| NFR-02 | 성능 | 목록은 24개 단위로 조회하고 캐시한다. 로컬 반복 조회 15ms 사례는 특정 측정값이며 공개 환경의 SLA를 보증하지 않는다. |
| NFR-03 | 신뢰성 | 동기화 체크포인트와 변경 해시를 사용한다. 오류를 빈 정상 결과나 저장 성공으로 바꾸지 않는다. |
| NFR-04 | 일관성 | 회원 데이터와 여행지 ID를 일관되게 연결한다. 편집 시 버전 조건으로 저장 충돌을 검사한다. |
| NFR-05 | 사용성 | 반응형 화면과 명확한 저장 상태, 페이지 나눔을 제공한다. 모바일·키보드 전체 검수는 별도 수행한다. |
| NFR-06 | AI 정직성 | 생성 결과와 미확인 정보를 표시한다. 예보·행사 실패와 직선거리 한계를 명시한다. |
| NFR-07 | 배포와 운영 | 외부 접근과 API 연결, 환경변수, 라우팅을 확인해야 한다. 주기 동기화의 서버 예약 실행은 별도 구성한다. |

# 시스템 아키텍처와 인터페이스

공개 데이터 조회와 개인 데이터 변경의 경계를 나눠 구성한다.

## 웹 계층

React와 React Router가 탐색, 일정 생성·편집, 커뮤니티, 호스트 화면을 구성한다. 인증은 Supabase SDK를 사용하고 Express 요청에는 세션의 Bearer 토큰을 전달한다.

## API 계층

Express는 인증과 입력 검증, 목록 및 활동 집계, 생성형 AI 연동을 담당한다. 일부 회원 일정 편집은 사용자 RLS가 적용된 Supabase SDK로 수행한다. 호스트 Agent는 Supabase Edge Function에서 실행한다.

## 주요 데이터

comm_place와 comm_place_tour_detail은 장소와 관광 상세를 연결한다. travel_itineraries는 회원별 일정, mytrip_wish는 찜, comm_post 계열은 글·리뷰·댓글을 저장한다. travel_tour_source와 sync_state는 원본 및 수집 상태를 관리한다.

| 인터페이스 | 역할 |
| --- | --- |
| GET /api/places | DB 목록과 검색 및 페이지 |
| POST /api/itineraries/generate | 입력·권역·외부 정보·LLM 생성 검증 |
| GET /api/mytrip/overview | 회원 일정과 찜·리뷰·과거 기록 |
| POST /api/mytrip/trips/:id/places | 선택한 일정·일차에 실제 장소 추가 |
| PUT /api/mytrip/wishes | 찜의 멱등 저장 및 취소 |
| POST /api/community/posts | 장소와 별점을 연결한 리뷰 생성 |
| Supabase SDK / Edge Function | 개인 일정 편집과 호스트 Agent |

참고: 상세 데이터·AI 실행 흐름과 수정 가능한 아키텍처 도식은 발표 PPT에 포함했다.
