## 확인된 정보와 남은 제출 항목

개발 기간은 팀에서 제공한 약 2주입니다. 시작·종료일과 개인별 기여 비율을 임의로 정하지 않았습니다. 팀원 역할은 제공받은 내용을 반영했습니다.

외부 사용자 최소 5명 테스트는 미실시입니다. 보고서의 과제와 기록 양식에 실제 수행 결과를 기록한 뒤 발표의 검증·운영 계획 장을 갱신합니다. 개발 중 요청과 자동 검사 결과를 실제 사용자 평가로 대체하지 않습니다.

Vercel 배포용 API 진입점과 SPA 라우팅을 구성했습니다. 실제 공개 URL, Auth 도메인·환경 변수 연결, 공개 운영 검증은 배포 후 확정합니다. Supabase Agent 배포와 관광정보 작업 스케줄은 별도 운영 단위입니다.

화면은 2026-10-26 실행 서비스에서 직접 촬영했습니다. 사진·지도 출처와 시연/AI 이미지 구분은 화면과 PPT 노트에 남겼습니다. 별도 발표자 대본은 포함하지 않습니다. 원문·전체 ZIP·제작 중간물·DB 원시 메타데이터 파일은 로컬 보관하고, 키·환경 설정·개인정보 행은 공개하지 않습니다.
